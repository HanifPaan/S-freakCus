# S-freakCus
SF custom server usage

## Tools

- [mailnager](mailnager/) - limits the Exim spool size and removes mail stuck too long, with auto-update ([notes](mailnager/notes/))
- [threat_watch](threat_watch) - reports visitors from chosen countries (default Indonesia) in a cPanel account's Apache logs every 3 hours as attack / scanner / fake bot / bot / normal, with country whitelist and editable rules
